CLOUD APK GENERATOR

Build Native APK on GitHub

सिर्फ HTML फाइल से सीधा APK नहीं बनता, इसलिए नीचे दिए गए बटनों से **4 ज़रूरी कॉन्फ़िगरेशन फाइल्स** डाउनलोड करें और उन्हें अपने GitHub Repository में अपलोड कर दें। GitHub Actions अपने आप आपके लिए फ्री में **Android `.apk`** तैयार कर देगा!

.github/workflows/build-apk.yml 
name: Build Android APK
on:
  push:
    branches: [ main, master ]
  workflow_dispatch:

jobs:
  build-apk:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Source Code
        uses: actions/checkout@v4

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: 20

      - name: Setup Java JDK 17
        uses: actions/setup-java@v4
        with:
          distribution: 'temurin'
          java-version: 17

      - name: Install Capacitor & Android Platform
        run: |
          mkdir -p www
          cp index.html www/index.html || true
          npm init -y
          npm install @capacitor/core @capacitor/cli @capacitor/android
          npx cap add android || true
          npx cap sync android

      - name: Build Debug APK with Gradle
        run: |
          cd android
          chmod +x gradlew
          ./gradlew assembleDebug

      - name: Upload Ready-to-Install APK
        uses: actions/upload-artifact@v4
        with:
          name: Matiks-Offline-APK
          path: android/app/build/outputs/apk/debug/app-debug.apk
